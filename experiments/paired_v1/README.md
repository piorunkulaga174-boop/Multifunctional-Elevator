# 相同冻结客流的配对实验

三组使用同一份预生成客流，随机种子为 42 到 51，每个种子生成 600 秒需求；随后继续服务直到完成。每次输入保存在 `inputs/seed_*.json`，详细 CSV 中的 SHA-256 可核对三组是否使用同一输入。此实验关闭额外随机行人；门区新到达者仍可触发现有防夹规则。专门的防夹演示使用独立场景。

本分支修正后的 10 次均值如下，不能与旧全功能组多生成行人的数值直接拼接比较。

| 指标 | 普通电梯 | 仅雷达 | 全功能 |
|---|---:|---:|---:|
| 总需求人数 | 90.1 | 90.1 | 90.1 |
| 完成行程人数 含收尾 | 73.6 | 74.0 | 73.8 |
| 放弃人数 | 16.5 | 16.1 | 16.3 |
| 平均等待秒数 | 76.64 | 72.81 | 71.14 |
| 空停率 | 7.21% | 2.58% | 3.24% |
| 每次仿真最长等待的均值 秒 | 168.0 | 160.0 | 206.5 |
| 防夹重开次数 | 0.0 | 0.0 | 0.9 |

这组小样本展示了固定输入下的结果，没有进行显著性检验。全功能平均等待较低，但最长等待指标较高，不能据此声称所有乘客均获益。防夹重开是仿真触发计数，不等于真实事故避免次数。
